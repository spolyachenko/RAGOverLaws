## Ключевые технологии / паттерны

- **Durable execution** — агент = хранимая процедура с графом исполнения; платформа владеет машиной состояния; переживает падение нод; **идемпотентность**: выполненные действия не повторяются
- **Agent bridge / «мост»** — слой между пользователем и агентом: перзистентность сообщений/намерений, асинхронный «сон» агента до ответа человека
- **EPP (Endpoint Picker)** — роутинг запросов к подам по взвешенной сумме: **префикс-кэш, глубина очереди, KV-занятость, z-score** (round-robin «не работает из-за KVCache»)
- **KV-cache leakage** — перетекание префиксного кэша одного пользователя к другому в multi-tenant; лечат солью на кэш
- **Disaggregated inference** — prefill/decode на разных GPU; общий KVCache через KVBM-ноды (строят)
- **GPU→GPU model transfer** — передача модели между GPU минуя CPU (разрабатывают)
- **Guardrails-фильтр** — inline-анонимизация: маскируем на входе в модель, подставляем оригиналы в ответ в том же чанке; fail-open + алерт; enterprise-версия в контуре клиента (98%)
- **Agentic identity / personality** — отдельные учетки/суб-идентити для агентов, делегирование полномочий, «на уровне OIDC и стандартов»
- **AI PDLC** — AI-driven Product Development Life Cycle (их white paper); GigaCode — «драйвер»
- **Policy engine в harness** — enterprise-ready: политики прямо в harness'е
- **Тестовые «корзины» + GigaEvo** — контролируемая эволюция: бенчи из анонимизированных production-данных, агент сам себя улучшает в изолированной среде
- **Nano mode** — экономный режим агентного цикла (~80k токенов)
- **MCP (Model Context Protocol), agent skills** — тулинг агентов; у Сбера — корпоративный маркетплейс скиллов
- **OpenSpec/SDD** — детерминированные спеки как контракт для агента («чем детерминированнее — тем ближе результат к ожиданиям»)
- **Agentic pipeline в CI/CD** — цепочки агентов (аналитик→разработчик→тестировщик→ревьюеры) в пайплайне; инфропотребление ~100x обычного CI/CD
- **Метрика агентной разработки** — задачи в релизе, коммиттер=агент, ≤1 человеческого касания (GitVerse: 16%)
- **Автоскейлинг по нагрузке модели, не по CPU** (комплексная: очередь+KV+токены)
- **Ночной инференс** — «инференс ночью практически бесплатный» (свои GPU); ночной тариф 23:00–06:00 в Foundation Models
- **Подписки Anthropic-формата** — тиры, 5-часовые/недельные лимиты, extra usage; анонс Foundation Models
- **NVFP4 / FP4 / FP8** — квантования; «если есть NVFP4/FP4 — кидаем на backfill-модели»
- **Envoy + LLM-фильтр** — data plane их гейтвея (model name из body → header, фазы req/res header/body/trailer)
- **AG-UI-«human-in-the-loop state»** — специальное сообщение + sleep до ответа пользователя
- **Physical AI** — визионерский прогноз Шипова на ближайшие годы
